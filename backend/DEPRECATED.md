# DEPRECATED - .NET Backend API

This directory contains a .NET C# API backend that **duplicates** the Python FastAPI backend.

## Status: DEPRECATED

**Decision Date**: 2025-11-11  
**Replaced By**: Python FastAPI (`api/`)

## Reason

The Python FastAPI backend (`api/`) is the primary backend and is fully functional. This .NET backend was an alternative implementation that is no longer needed.

This directory can be safely removed.
